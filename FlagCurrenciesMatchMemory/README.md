# Flag & Currency Match - Memory Game 🎮

A fun and educational desktop web-based memory game where players match country flags with names or currencies with country names.

## Features

- 🚩 **Flag Mode**: Match country flags with their names
- 💰 **Currency Mode**: Match currencies with country names
- 🎯 **Three Difficulty Levels**: Easy (4×4), Medium (5×6), Hard (6×6)
- 🤖 **Bot Opponent**: Play against AI with 3 difficulty levels
- ⭐ **Scoring System**: Track moves, time, and earn stars
- 🎨 **Beautiful UI**: Smooth animations and modern design
- 🌍 **Real Data**: Uses REST Countries API for live data

## How to Run

### Method 1: VS Code Live Server (Recommended)
1. Install "Live Server" extension in VS Code
2. Right-click `index.html` → "Open with Live Server"

## How to Play

1. **Select Game Mode**: Choose between Flag or Currency mode
2. **Choose Difficulty**: Easy, Medium, or Hard
3. **Optional Bot Mode**: Toggle VS Bot and select bot difficulty
4. **Click Start Game**: Cards will be shuffled and displayed
5. **Flip Cards**: Click cards to reveal them
6. **Match Pairs**: Find matching pairs (Flag+Name or Currency+Name)
7. **Win**: Match all pairs to see your score!

## Technologies Used

- Pure HTML5, CSS3, JavaScript (Vanilla JS)
- REST Countries API
- CSS Grid & Flexbox
- CSS Animations & Transforms
